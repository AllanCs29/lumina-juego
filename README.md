# Lúmina — Señales del Norte

**v0.4.4 · Aprende jugando**. Videojuego de aventura y programación desde cero para iPhone horizontal y PC.

[Jugar](https://allancs29.github.io/lumina-juego/)

## La filosofía actual
Primero explorar y experimentar, después explicar brevemente el resultado. Los detalles siguen accesibles en el Cuaderno progresivo y mediante los botones ⓘ Aprender. No hay clases obligatorias antes de usar las consolas.

## Contenido
- Prólogo original de 4 escenas cortas con avance automático.
- Lógica booleana de sensores para abrir Z02.
- Variable numérica `carga` que construye un puente real.
- Secuencias para programar NIX y bucles para encender el faro.
- Distrito Aurora, Azoteas, Estación Umbral, Archivo de Ecos, Puerto, Pasarela Boreal y Faro.
- Controles táctiles personalizables, guardado y modos 60/120 FPS experimentales.

## Desarrollo
El archivo `index.html` de este repositorio es la página jugable en GitHub Pages. El ZIP completo de la entrega incluye código modular, pruebas y el archivo HTML independiente.
