# Lúmina — Señales del Norte

Una aventura de plataformas y exploración donde Iris y NIX reactivan máquinas, descubren señales y resuelven desafíos de lógica de programación.

**[Jugar en el navegador](https://allancs29.github.io/lumina-juego/)**

## El juego

Recorre escenarios invernales, encuentra memorias, resuelve puzles, supera obstáculos y activa mecanismos mediante secuencias de instrucciones, variables, condiciones y ciclos. El viaje concluye en el Faro del Silencio, donde debes verificar qué señales pueden transmitirse sin peligro. La programación se introduce gradualmente, empezando por lógica y pseudocódigo.

Incluye checkpoints, guardado local, práctica de programación con bloques, opciones de accesibilidad y controles para teclado o pantalla táctil.

## Controles

| Acción | Teclado |
| --- | --- |
| Moverse | A / D o flechas |
| Saltar | Espacio |
| Interactuar | E |
| Impulso | Shift |

El tutorial de controles también está disponible desde el menú. En dispositivos táctiles se muestran controles en pantalla. También se admiten mandos con distribución estándar: palanca o cruceta para moverse, A para saltar, B o RB para impulso, X/Y para interactuar y Start para abrir el menú. La conexión es opcional y no sustituye al teclado ni a los controles táctiles.

## Tecnología

Juego 2D creado con **HTML, CSS y JavaScript**, renderizado mediante **Canvas**. Funciona como aplicación web progresiva (PWA) y puede usarse sin conexión después de su primera carga.

El proyecto se publica en GitHub Pages. El punto de entrada es `index.html`.
