📖 ¿Cómo funciona? Ver el pseudocódigo explicado
   
Una receta para la máquina: INICIO indica dónde empieza; ← guarda un valor en la cajita; SI toma una decisión; FIN termina la receta.

   
INICIO
  carga ← 1
  // Agrega bloques para transformar el valor
  SI carga = 5 ENTONCES
    ABRIR puente
  FIN SI
FIN
